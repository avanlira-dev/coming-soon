# Avanlira Static Landing Page (GitHub Pages Ready)

This directory contains a complete, standalone static HTML/CSS/JS export of the **Avanlira Landing Page**.

## Features Included
- **Zero Build Dependencies**: Pure HTML5, Tailwind CSS (via CDN), Lucide Icons, and Vanilla JS.
- **Coming Soon Integration**: All "Sign In", "Sign Up", and "Start Free" actions have been replaced with a stylish **Coming Soon** badge and modal alert.
- **All Required Assets**:
  - `avanlira-logo.png`
  - `avanlira-mark.svg`
  - `avanlira-mark-reversed.svg`
  - `bakery-social-post.jpg`
  - `bakery-ad-video.mp4`
- **Interactive UI**:
  - Billing Interval Switcher (Monthly / Annual pricing in INR).
  - Responsive Mobile Drawer Menu.
  - Interactive "Compare All Plans" Modal.
  - Interactive "Coming Soon" Modal for feature previews.
  - HTML5 video player with fallback poster.

## How to Host on GitHub Pages

1. Create a new GitHub repository (e.g. `avanlira-landing`) or create a `gh-pages` branch in your existing repository.
2. Push all files inside this `static-landing` folder directly to the repository root.
3. In GitHub Repository **Settings** -> **Pages**:
   - Source: **Deploy from a branch**
   - Branch: `main` / `root`
4. Click **Save**. Your static site will be live instantly!
