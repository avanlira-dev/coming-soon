# Avanlira Static Landing Page (Early Access & GitHub Pages)

This directory contains a standalone, production-ready static HTML/CSS/JS export of the **Avanlira Landing Page** configured for pre-launch early access collection.

## Key Updates & Features
- **Early Access Waitlist Form**: Interactive waitlist popup modal collecting Name, Email, and Business Name/Type. Saves entries locally to `localStorage` and displays a confirmation success screen.
- **Indian Business Demo Context**: Replaced all UK demo examples with **Bean & Bloom · Jubilee Hills, Hyderabad** (specialty South Indian coffee & cardamom croissants).
- **Clear "Coming Soon" & "Demo Data" Badging**: Prominent badges and clear data disclaimers so visitors know the product is under active development.
- **Planned Launch Pricing**: Pricing section updated to **Planned Launch Pricing** in INR.
- **Support Contact Email**: Updated to `avanlira.official@gmail.com`.
- **Hero Trust Copy**: Updated to `"Free plan available at launch · No card required · 20 free AI content creations"`.

## Hosting on GitHub Pages
1. Push the contents of `static-landing` to your GitHub repository or `gh-pages` branch.
2. Under Repository **Settings** -> **Pages**, set source to `root` or `gh-pages`.
3. Save to deploy.
